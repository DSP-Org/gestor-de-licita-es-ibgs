================================================================================
                         COMO USAR CADA FEATURE
================================================================================

1. REORDENAR LISTAS
   Ir para "Favoritas" → Passar mouse sobre lista → Arrastar → Pronto!

2. EXPORTAR
   Selecionar lista → Clicar icone exportacao → Escolher PDF/Excel

3. COMPARTILHAR
   Selecionar lista → Clicar icone compartilhar → Escolher canal

4. VER STATS
   Selecionar lista → Dashboard aparece automaticamente

5. VINCULAR LICITACAO
   Abrir licitacao → Campo "Adicionar à lista" → Selecionar → Salvar
